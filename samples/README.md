# samples

试用 BoneCode 用的素材，不影响应用本身。

| 文件 | 用来试什么 |
|---|---|
| `Demo.java` | Java 语法高亮、代码补全（`sout` / `fori`）、括号配对、`⌘⌥F` 缩进重排 |
| `Demo.vue` | Vue 混合语法：`<template>` 按 HTML、`<script setup>` 按 TS、`<style scoped>` 按 CSS |
| `spring/` | 运行面板的项目探测。把 `samples/spring` 作为项目打开（⌘⇧O），应识别出 Spring Boot 与端口 8080 |

逐项清单见仓库根目录的 `TESTING.md`。

`spring/` 在 `feature/spring-sample` 分支上。想练手 cherry-pick，可以在「Git → 历史」
里选中那条提交，右键「挑拣到当前分支」。
